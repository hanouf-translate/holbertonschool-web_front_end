Foundation

<!DOCTYPE html>

Declaration

The doctype is necessary at the top of every HTML page to force the browser to render the page according to the relevant specifications. It is the only element living outside the <html> tag.

<!DOCTYPE html>
ResourcesDoctype — MDN

<html>

Root

The <html> tag tells the browser that the document is an HTML webpage. It is used as a container for all the HTML elements. The doctype is the only thing living outside of it.

<html lang="en" dir="ltr">
  <head>...</head>
  <body>...</body>
</html>
💡Language & reading direction: always set lang and, when relevant, dir="rtl" to build RTL-aware web apps and websites.
ResourcesMDN·Building RTL-Aware Web Apps & Websites

<head>

Metadata

The <head> element contains all the metadata related to your page. Everything inside it is not visible in the browser window.

Common contents
  • Title of the page
  • Asynchronous script calls
  • Metadata
  • Critical CSS embed
  • JavaScript embed
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page title</title>
  <link rel="stylesheet" href="styles.css">
  <script src="app.js" async></script>
</head>
ResourcesHEAD — A free guide to head elements

<meta charset>

Metadata

The meta charset declares the page’s character encoding. It should appear as the very first element inside <head>.

<meta charset="UTF-8">
Resourcesmeta — MDN·Declaring character encodings in HTML

<meta viewport>

Metadata

The meta viewport gives information about the initial size of the viewport. It is used by mobile devices only.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
♿Accessibility tip: never use maximum-scale=1.0. It prevents the user from zooming in and causes an accessibility issue.
ResourcesResponsive Design With Viewport Control

<title>

Metadata

The title element defines the title of the web page. It is only visible on the tab/window of your browser.

<title>Page title</title>
⚠️Warning! The title should always have fewer than 56 characters.
ResourcesThe ideal width of the SEO title — Yoast

<meta name="description">

Metadata

The meta description provides a short summary of the page that search engines may display in results.

<meta name="description" content="A short summary of the page for search engines.">
ResourcesThe ideal length of a meta description — Yoast

Favicons

Metadata

Favicons are the small icons shown in browser tabs, bookmarks, and on mobile home screens. Provide multiple formats for broad platform support.

<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
ResourcesFavicon & App Icon Generator·Obsessive cheat sheet to favicon sizes/types·PNG favicons — caniuse

Tag attributes

Syntax

Attributes provide additional information or instructions for an HTML element. They are always included inside the opening tag.

<a href="https://example.com" target="_blank" rel="noopener">Link</a>
ResourcesHTML attribute reference — MDN

<div data-*>

Custom data

It is possible to declare any custom attribute using the data- prefix. These attributes store extra information on the element without any visual effect.

<div data-user-id="42" data-role="admin">
  Some content
</div>
Resourcesdata-* — MDN

Page Structure

<header>

Block

The <header> element identifies the top of a webpage, article, section, or other segment of a page. The header is normally the same across all pages of your website.

Common usage
  • Logo of the website
  • Navigation
  • Search form
<header>
  <a href="/"><img src="logo.svg" alt="My Website"></a>
  <nav>...</nav>
</header>
⚠️Don’t confuse <header> with the <head> element of the page.
Resourcesheader — MDN

<main>

Block

The <main> element is a structural element located generally between the <header> and the <footer>. It contains the primary content of your web page.

<header>This is my header</header>
<main>
  <h1>Welcome</h1>
  <p>This is where I put my content.</p>
</main>
<footer>This is the footer</footer>
⚠️Warning! The <main> element should never be a descendant of an <article>, <aside>, <header>, <footer>, or <nav> element.
Resourcesmain — MDN

<footer>

Block

The <footer> element is a structural element used to identify the footer of a page, article, or section.

Common usage
  • Copyright information
  • Authorship information
  • Navigation elements
  • Social icons or links
<footer>
  <p>&copy; 2024 My Website — All rights reserved.</p>
</footer>
Resourcesfooter — MDN

<aside>

Block

The <aside> element contains additional information related to the main content.

Common usage
  • Monthly archives
  • List of categories
<aside>
  <h3>Categories</h3>
  <ul>
    <li><a href="/html">HTML</a></li>
    <li><a href="/css">CSS</a></li>
  </ul>
</aside>
Resourcesaside — MDN

<section>

Block

The <section> element allows the grouping of related elements. You can usually find a <header> and <footer> attached to a section.

<section>
  <h2>Section 1</h2>
  <p>Related content goes here.</p>
</section>
Resourcessection — MDN

<article>

Block

An <article> represents a self-contained piece of content which could theoretically be distributed to other websites and platforms as a stand-alone unit.

Common usage
  • Blog posts
  • News articles
  • Product cards
  • Forum posts
<article>
  <h2>Article 1</h2>
  <p>Article content...</p>
</article>
Resourcesarticle — MDN

<nav>

Block

The <nav> element is a structural element containing navigation links.

<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
    <li><a href="/contact">Contact</a></li>
  </ul>
</nav>
Resourcesnav — MDN

Text & Content

<h1> – <h6>

Block

Headings are used to define a section heading. Browsers apply different default sizes for each level, but HTML is about content — not styling.

<h1>This is my title level 1</h1>
<h2>This is my title level 2</h2>
<h3>This is my title level 3</h3>
⚠️Warning! Never use an <h4> after an <h2>. Always keep a descendant order: h1 > h2 > h3 …
♿Accessibility tip: headings are used by voice browsers to help navigate through the webpage.
💡Never put the logo or name of your website inside an <h1>. The text inside must reflect the content of your page. On a homepage you can visually hide your <h1>, but it should still exist in the code.
Resourcesh1–h6 — MDN

<p>

Block

A <p> defines a paragraph of text.

<p>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</p>
⚠️Warning! If you need a container to wrap multiple elements, use <div> instead of <p>. Only use the paragraph tag when the content could be considered a paragraph of text.
Resourcesp — MDN

<span>

Inline

A <span> is a generic inline container used usually for text that is not inside a paragraph. It has no semantic meaning and should be used as little as possible.

<p>This is <span class="highlight">my first span</span>.</p>
Resourcesspan — MDN

<div>

Block

A <div> (stands for “document division”) is a generic block of content used to structure elements in your layout. Like <span>, it carries no semantic meaning.

<div class="card">
  <p>This is my first div.</p>
</div>
Resourcesdiv — MDN

<!-- -->

Comment

Comments allow you to add information visible to the developer but not to the normal user. Comments are not rendered on the page.

<!-- This is a comment. It is not visible on the page. -->
ResourcesAbout conditional comments (Internet Explorer) — Microsoft Docs

Links & Lists

<a>

Inline

Links are inline elements which allow you to navigate from one page or document to another.

Three types of targets
  • Anchor targets — navigate within the same page
  • Relative URLs — navigate within the same website
  • Absolute URLs — navigate to another website
<a href="#section">Anchor link</a>
<a href="/about">Relative URL</a>
<a href="https://example.com" target="_blank" rel="noopener">Absolute URL</a>
⚠️If you use target="_blank", don’t forget to add rel="noopener" for security purposes.
Resourcesa — MDN·About rel=noopener·Mailto Links — CSS-Tricks

<ol> · <ul> · <dl>

Block

Lists are used for listing ingredients in a recipe, a series of social icons, and more. Use <ol> for ordered lists, <ul> for unordered lists, and <dl> for definition lists.

<ol>
  <li>List item 1</li>
  <li>List item 2</li>
  <li>List item 3</li>
</ol>

<ul>
  <li>First bullet point</li>
  <li>Second bullet point</li>
  <li>Third bullet point</li>
</ul>

<dl>
  <dt>Term</dt>
  <dd>Definition of the term</dd>
  <dt>Another term</dt>
  <dd>Another definition of the term</dd>
</dl>
Resourcesul — MDN·ol — MDN·dl — MDN

<hr>

Void

An <hr> is a semantic break that separates different blocks of text.

<p>Lorem ipsum dolor sit amet.</p>
<hr>
<p>Section two begins here.</p>
Resourceshr — MDN

<br>

Void

Line breaks are used to break text onto multiple lines.

<p>Lorem ipsum dolor sit amet.<br>Donec viverra nec nulla vitae mollis.</p>
⚠️Never use line breaks for presentation purposes — to create space between elements. Spacing and layout should only be handled by CSS.
Resourcesbr — MDN

Quotations

<q>

Inline

Inline quotes are used for inline text that doesn’t require paragraph breaks.

<p>According to Mozilla's website, <q>Firefox 1.0 was released in 2004 and became a big success.</q></p>
Resourcesq — MDN

<blockquote>

Block

A multiline quote is called a blockquote.

<blockquote cite="https://example.com">
  <p>People think focus means saying yes to the thing you've got to focus on.
  But that's not what it means at all. It means saying no to the hundred other
  good ideas that there are.</p>
  <footer>— Steve Jobs, Apple Worldwide Developers’ Conference, 1997</footer>
</blockquote>
Resourcesblockquote — MDN

Inline Semantics

<em> · <i> · <strong> · <b>

Inline

These tags give semantic meaning to text. They may look the same visually in some browsers, but HTML is about content and semantics, not the visual aspect.

Meaning
  • <em> — stress emphasis
  • <i> — text set off from the normal prose (foreign word, technical term…)
  • <strong> — stronger importance
  • <b> — draw attention (keywords in a summary, product names…)
<p>I <em>really</em> like driving in San Francisco.</p>
<p>The term <i>voilier</i> is a french word which means "sailing ship".</p>
<p><strong>Warning!</strong> This is not a drill.</p>
<p>This text is <b>bold</b>.</p>
Resourcesem·i·strong·b

<small> · <del> · <ins> · <s> · <mark>

Inline

These tags annotate edits, comments, and highlighted text.

Meaning
  • <small> — side-comments or small text (copyright, legal…)
  • <del> — deleted text
  • <ins> — inserted text
  • <s> — text with a strikethrough
  • <mark> — relevance / highlighted text
<p><small>&copy; 2024 My Website. All rights reserved.</small></p>
<p>I received <del>$500</del> <ins>$1000</ins> for that job!</p>
<p><s>$500</s> $1000</p>
<p>This whole text should be <mark>highlighted in yellow</mark>.</p>
Resourcessmall·del·ins·s·mark

<cite> · <dfn> · <abbr> · <code> · <time> · <wbr> · <address>

Inline

These tags give precise semantic meaning to technical, metadata, and contact information.

Meaning
  • <cite> — name of a work (book, play, song…)
  • <dfn> — defining instance of a term
  • <abbr> — abbreviation or acronym
  • <code> — short fragment of computer code
  • <time> — specific period in time
  • <wbr> — opportunity for a line break
  • <address> — contact information
<p><cite>Atomic Habits</cite> by James Clear</p>
<p>The <dfn>HTML Definition element</dfn> is used to indicate a term being defined.</p>
<p>You are the <abbr title="Cascading Style Sheets">CSS</abbr> of my HTML.</p>
<p>Use <code>console.log()</code> to debug.</p>
<p>Published on <time datetime="2019-09-19">Sept 19, 2019</time></p>
<p>I want to understand what<wbr>is<wbr>going<wbr>on!</p>
<address>
  Contact <a href="mailto:someone@example.com">someone@example.com</a>
</address>
Resourcescite·dfn·abbr·code·time·wbr·address

Data

<table>

Block

A table element is used to wrap tabular content. It uses rows and columns to organize the data.

Anatomy of a table
  • <caption> — title of the table
  • <thead> — header rows
  • <tbody> — body rows
  • <tfoot> — footer rows
  • <th> — header cell
  • <tr> — row of cells
  • <td> — data
